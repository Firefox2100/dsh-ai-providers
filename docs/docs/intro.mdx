DSH AI Providers is a common AI capability layer for [DeepSeek Harness](https://github.com/DeepSeek-AI/DeepSeek-Harness) plugins. A user registers a vendor connection and DSH-managed credential once; every supported capability and every consumer plugin can reuse it. Plugin developers depend on stable services rather than rebuilding credential forms, provider selection, concurrency control, and vendor transports.

The current services are:

- embeddings and reranking;
- text-to-speech and speech-to-text;
- image generation;
- OpenAI-compatible language-model routes.

Install the runtime and one or more vendor plugins. Configure reusable connections in the DSH settings UI, select a provider for each capability, then consume the selected service from the Cordis context.

This is a foundation, not a standalone end-user feature. Installing it by itself does not add an AI assistant or make requests. It becomes useful when another plugin consumes its services, or when a developer builds such a plugin. The separation lets users change providers without forcing each consuming plugin to implement or understand every vendor.

Future releases will add more vendor packages, services, and vendor-specific controls while keeping the shared consumer contracts focused and stable.

## Included packages

| Package | Purpose |
| --- | --- |
| `@dsh-ai-providers/core` | Provider-neutral contracts, errors, and shared types |
| `@dsh-ai-providers/openai-compatible` | Shared OpenAI-compatible wire transports; not a plugin |
| `@dsh-ai-providers/runtime` | Provider registry, selected services, settings UI, API routes, and concurrency control |
| `@dsh-ai-providers/openai` | OpenAI-compatible embeddings, LLM, TTS, STT, and image generation |
| `@dsh-ai-providers/localai` | LocalAI embeddings, reranking, LLM, TTS, STT, and image generation |
| `@dsh-ai-providers/anthropic` | Anthropic-native language models |
| `@dsh-ai-providers/jina-cohere` | Jina and Cohere compatible reranking |
| `@dsh-ai-providers/all` | Metadata-only bundle containing the runtime and all providers maintained by this project |

Start with [Installation](./getting-started/installation), or go directly to [Using services](./consumers/using-services) if you are integrating another plugin.

## Providers maintained by this project

These packages are maintained by Firefox2100 as part of this independent project. They are not official DeepSeek Harness packages and are not maintained or endorsed by the DSH maintainers.

This project currently maintains four vendor packages:

- [`@dsh-ai-providers/openai`](./official-providers/openai): OpenAI-compatible language models, embeddings, TTS, file and live STT, and image generation;
- [`@dsh-ai-providers/localai`](./official-providers/localai): first-class LocalAI language models, embeddings, reranking, speech, and image generation;
- [`@dsh-ai-providers/anthropic`](./official-providers/anthropic): language models through Anthropic's native Messages API;
- [`@dsh-ai-providers/jina-cohere`](./official-providers/jina-cohere): Jina- and Cohere-compatible reranking.

Third-party provider plugins can implement the same contracts and appear in the same settings UI.
