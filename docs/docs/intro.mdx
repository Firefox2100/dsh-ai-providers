DSH AI Providers gives [DeepSeek Harness](https://github.com/DeepSeek-AI/DeepSeek-Harness) plugins a shared interface for common AI capabilities:

- embeddings and reranking;
- text-to-speech and speech-to-text;
- image generation;
- OpenAI-compatible language-model routes.

Install the main plugin and one or more vendor plugins. Configure reusable connections in the DSH settings UI, select a provider for each capability, then consume the selected service from the Cordis context.

## Included packages

| Package | Purpose |
| --- | --- |
| `dsh-ai-core` | Provider-neutral contracts, errors, and shared types |
| `dsh-ai-providers` | Provider registry, selected services, settings UI, API routes, and concurrency control |
| `dsh-ai-openai` | OpenAI-compatible embeddings, LLM, TTS, STT, and image generation |
| `dsh-ai-localai` | LocalAI embeddings, reranking, LLM, TTS, STT, and image generation |
| `dsh-ai-anthropic` | Anthropic-native language models |
| `dsh-ai-jina-cohere` | Jina and Cohere compatible reranking |

Start with [Installation](./getting-started/installation), or go directly to [Using services](./consumers/using-services) if you are integrating another plugin.

## Officially maintained providers

This project currently maintains three vendor packages:

- [`dsh-ai-openai`](./official-providers/openai): OpenAI-compatible language models, embeddings, TTS, file and live STT, and image generation;
- [`dsh-ai-localai`](./official-providers/localai): first-class LocalAI language models, embeddings, reranking, speech, and image generation;
- [`dsh-ai-anthropic`](./official-providers/anthropic): language models through Anthropic's native Messages API;
- [`dsh-ai-jina-cohere`](./official-providers/jina-cohere): Jina- and Cohere-compatible reranking.

Third-party provider plugins can implement the same contracts and appear in the same settings UI.
