在 DSH 中打开 **设置 → AI Providers**。配置分为三层。

## 1. 创建可复用连接

连接包含稳定 ID、显示名称、基础 URL，以及 DSH 所存凭据的引用。密钥由 DSH 凭据服务管理；插件配置只保存引用，且不会将密钥返回浏览器。无需认证的服务器可将凭据引用留空。

同一个连接可供多种能力复用。例如，一个 LocalAI 连接可以同时提供嵌入、语音、图像和语言模型服务。

## 2. 配置提供方能力

每个提供方插件都有自己的设置。选择连接，再配置模型和能力专属选项。OpenAI 兼容插件提供默认值，但兼容服务器通常采用不同的模型或声音名称。

删除连接不会删除它引用的凭据，以免一个插件误删其他配置仍在使用的密钥。

## 3. 选择活动服务

为以下各项能力选择一个已注册的提供方：

- 文本嵌入；
- 重排；
- 文本转语音；
- API 语音转文本；
- 图像生成。

选择会立即生效，无需重启。选择**禁用**会从上下文中移除该能力服务。语言模型路由有所不同：所有已配置的提供方路由都可以同时供 DSH 使用。

## DSH 内置语音转文本

DSH 可能提供自己的 `speechToText` 注册表。若要使用 DSH 语音输入，请保留该注册表：本插件会将当前选择的 API 转录提供方注册到其中。请在 DSH 的语音转文本设置中选择该 API 提供方，而不是内置的 SenseVoice 提供方。需要使用已配置 API 时，不要继续将 SenseVoice 设为默认提供方。

与提供方无关的文件转录服务始终可直接通过 `apiSpeechToText` 使用；如提供方支持实时转录，则另行提供 `streamingSpeechToText`。

## 命名与变更管理

连接 ID 和语言模型路由 ID 是持久引用，不是展示标签。请选择简短稳定的 ID；需要改善措辞时只改显示名称。重命名 ID 可能破坏仍引用旧值的能力选择或聊天模型设置。

描述连接或模型的配置字段会在设置边界验证。提供方专属标识符应与上游服务发布的值完全一致；本项目不会把友好模型名或声音名转换为未记录的厂商 ID。

## 每次测试一项能力

先使用端点明确实现的连接和一项能力，确认成功后再启用其他服务。OpenAI 兼容基础 URL 可能支持聊天但不提供语音或图像；LocalAI 部署也只会公开实际加载的后端。

测试失败时，使用规范化错误码区分配置与可用性：`not-configured` 指向选择或加载状态；`rejected` 通常指向凭据、配额、策略或标识符；`unavailable` 指向网络、超时或提供方健康。完整表格见[故障排查](../reference/troubleshooting)。

## 并发默认策略

在出现真实共享限制前，可以不启用门控；也可以添加匹配受限提供方、路由或能力的规则。索引和维护任务使用后台优先级；只有这些任务可能延迟交互时才预留容量。状态视图会显示哪条规则正在占用或排队调用。
