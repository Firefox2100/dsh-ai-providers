## `dsh-ai-core`

提供嵌入、重排、语音、图像、提供方、调用选项和统一错误的公共接口。使用方和提供方插件都应从此包导入共享类型。

## `dsh-ai-providers`

运行时协调插件，提供注册表、所选能力服务、设置及认证配置 API、健康检查、DSH 语言模型路由、并发调度和嵌入去重。

## `dsh-ai-openai`

提供 OpenAI 兼容的嵌入、语言模型对话与流、TTS、文件与实时 STT，以及图像生成。兼容服务器可能只实现其中一部分；应只启用并选择服务器实际提供的能力。

## `dsh-ai-jina-cohere`

实现 Jina 和 Cohere 兼容的 `/rerank` API。连接与凭据的复用方式和 OpenAI 连接一致。
