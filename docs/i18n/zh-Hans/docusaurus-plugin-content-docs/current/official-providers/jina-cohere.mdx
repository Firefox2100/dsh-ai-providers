`dsh-ai-jina-cohere` 是本项目官方维护的重排提供方。它支持 Jina AI、Cohere 共用的 `POST /rerank` 格式，以及部分 LocalAI、vLLM 等兼容部署。

## 配置连接

创建一个或多个包含 ID、名称、基础 URL 和 DSH 凭据引用的连接。默认配置为：

| 设置 | 默认值 |
| --- | --- |
| 基础 URL | `https://api.jina.ai/v1` |
| 凭据引用 | `JINA_API_KEY` |
| 模型 | `jina-reranker-v2-base-multilingual` |
| 超时 | 60 秒 |

使用 Cohere 或其他兼容服务器时，更改基础 URL、凭据引用和模型。基础 URL 应为 `/rerank` 之前的路径前缀。

随后打开重排能力标签页，选择 **Jina / Cohere compatible** 作为活动提供方。

## 兼容行为

请求包含 `model`、`query`、`documents`、可选 `top_n` 及 `return_documents: false`。响应可使用 `relevance_score` 或 `score`；如存在 Jina 或 Cohere 风格的 token 用量字段，服务也会读取它。

服务会验证空问题和空文档，按分数降序排列结果，并将原始 logit 归一化到服务接口规定的 0–1 范围。

使用示例请参阅[重排](../services/reranking)。
