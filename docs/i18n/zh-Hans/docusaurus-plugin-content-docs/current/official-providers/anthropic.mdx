`@dsh-ai-providers/anthropic` 是 Firefox2100 在本项目中维护的 Anthropic 原生提供方。它直接使用 Messages API，而不是通过 OpenAI 兼容端点转换请求。它不是 DSH 或 Anthropic 官方软件包。

## 支持能力

| 能力 | 原生端点 |
| --- | --- |
| 语言模型 | `POST /messages` |
| 模型发现 | `GET /models` |

Anthropic 不提供嵌入、重排、TTS、STT 或图像生成 API，因此本软件包不会注册这些服务。

## 配置连接

安装软件包后打开 **设置 > 提供方 > Anthropic 连接**。默认连接使用：

![DSH 设置中的 Anthropic 连接和凭据引用](/img/screenshots/providers/anthropic-settings.png)

| 设置 | 默认值 |
| --- | --- |
| 基础 URL | `https://api.anthropic.com/v1` |
| 凭据引用 | `ANTHROPIC_API_KEY` |
| API 版本 | `2023-06-01` |
| 流静默上限 | 5 分钟 |

密钥通过 DSH 凭据服务保存。原生请求使用 `x-api-key` 认证，并携带配置的 `anthropic-version` 请求头。需要测试功能时，可以添加路由专属请求头。

## 配置路由与模型

创建具名路由，选择连接，再添加准确的 Anthropic 模型 ID。提供方可通过 `/models` 发现可用模型，也可以手动输入。每个模型可以声明上下文窗口、输出上限、图像支持及推理等级。

推理等级是原生请求片段。例如，支持自适应思考的模型可以使用：

```json
{
  "thinking": {"type": "adaptive"},
  "output_config": {"effort": "high"}
}
```

这些字段必须与所选模型一致；不同代际模型的思考控制有所不同。

## 原生请求映射

提供方支持：

- 顶层系统提示；
- 文本和图像内容；
- 原生工具声明、`tool_use` 和 `tool_result` 块；
- 流式文本、思考和工具输入；
- 提示缓存读写用量；
- `temperature`、`top_p`、`top_k`、停止序列、输出上限和工具选择；
- 通过路由或模型配置添加其他原生请求字段。

文件仍以工具可读取的文本句柄表示。已卸载图像保持占位符；其他图像从 DSH 附件服务读取，并作为 base64 来源发送。

## 错误与取消

HTTP 和流错误会映射到 DSH 语言模型失败分类，包括认证、限流、过载、无效请求、上下文溢出、超时和取消。响应包含 `retry-after` 或 Anthropic 请求 ID 时也会保留。
